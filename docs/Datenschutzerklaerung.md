# Datenschutzerklärung (Privacy Policy)

**Stand:** 17. August 2026  
**Geltungsbereich:** Discord-Bot „Filpo01 Community Bot"

---

## 1. Verantwortlicher

Der Verantwortliche für die Datenverarbeitung ist der Betreiber des Bots. Kontakt über den Discord-Server, in dem der Bot aktiv ist.

## 2. Erhobene Daten

Der Bot erhebt **ausschließlich technisch notwendige Daten** und speichert diese nur lokal auf dem Server:

| Daten | Zweck | Speicherdauer |
|-------|-------|---------------|
| Discord-User-ID | Befehlszuordnung, Moderation | Nur bei Befehlsnutzung |
| Discord-Nutzername | Anzeige in Befehlen | Nur bei Befehlsnutzung |
| Warnungen | Moderation (max. 5 pro User) | Bis zum Löschen durch Admin |
| Ticket-Nachrichten | Support-System | Bis zum Schließen des Tickets |
| Twitch/YouTube-Kanalname | Benachrichtigungs-System | Nur bei aktiver Abonnement |
| XP/Level-Daten | Leveling-System | Lokal, keinexterner Zugriff |

## 3. Keine Weitergabe an Dritte

- Es werden **keine Daten** an Dritte weitergegeben.
- Es werden **keine Daten** an externe Server gesendet (außer Discord API für Bot-Funktionalität).
- Es werden **keine Cookies** oder Tracking-Technologien eingesetzt.

## 4. Discord API

Der Bot nutzt die offizielle Discord API. Dabei können Technische Daten (z.B. IP-Adressen) an Discord übertragen werden. Dies unterliegt der Datenschutzerklärung von Discord: https://discord.com/privacy

## 5. Rechtsgrundlage

Die Datenverarbeitung erfolgt auf Grundlage von:
- **Art. 6 Abs. 1 lit. f DSGVO** (Berechtigtes Interesse) — Bot-Funktionalität
- **Art. 6 Abs. 1 lit. a DSGVO** (Einwilligung) — Optionaler Nutzung von Features

## 6. Betroffenenrechte

Sie haben das Recht auf:
- **Auskunft** über gespeicherte Daten (Art. 15 DSGVO)
- **Berichtigung** falscher Daten (Art. 16 DSGVO)
- **Löschung** Ihrer Daten (Art. 17 DSGVO)
- **Widerspruch** gegen die Datenverarbeitung (Art. 21 DSGVO)

Zur Ausübung dieser Rechte wenden Sie sich an den Bot-Betreiber über den Discord-Server.

## 7. Löschung

- **Ticket-Daten:** Werden beim Schließen des Tickets automatisch gelöscht.
- **Warnungen:** Können durch einen Admin jederzeit gelöscht werden.
- **Leveling-Daten:** Können durch Admin-Befehl zurückgesetzt werden.
- **Benachrichtigungen:** Können jederzeit durch den User entfernt werden.

## 8. Änderungen

Diese Datenschutzerklärung kann jederzeit geändert werden. Änderungen werden auf dem Discord-Server bekanntgegeben.

## 9. Kontakt

Bei Fragen zum Datenschutz wenden Sie sich an den Bot-Betreiber über den Discord-Server.
